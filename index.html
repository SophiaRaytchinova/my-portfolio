01

Calorix Fitness System

Код в GitHub ↗
  • C++17
  • ООП
  • Design Patterns
  • 0/1 Knapsack
  • Файлови бази

Конзолна система за проследяване на хранене и тренировки. Има потребители с различни роли: трениращите записват храна и упражнения, а администраторът поддържа базите с данни. Калкулира BMI и BMR (формулата на Mifflin-St Jeor), показва дневна сума на калории и макроси и следи напредъка към цел.

Генерирането на тренировъчен план е решено като задача за раницата (0/1 knapsack): за зададено време се избират упражнения, които изгарят най-много калории.

Архитектурни акценти: абстрактен клас User с наследници Admin и Trainee, UserFactory за създаване на потребители, Repository хранилища и ясно разделение в include/ и src/.
02

Pure Strategy

Код в GitHub ↗
  • C++
  • STL
  • Fisher-Yates
  • Валидация на вход

Конзолна версия на картовата игра Pure Strategy за двама играчи, направена като финален проект. Всеки има по 13 карти и във всеки рунд залага карта, за да вземе наградата от общото тесте. Има регистрация, вход и запис на статистиката в .txt файл след края на играта.

Архитектурни акценти: разбъркване на тестето с алгоритъма на Fisher-Yates, защита срещу невалиден потребителски вход и логика за пренасяне на наградата при равенство.
03

Console Tower Defense

Код в GitHub ↗
  • C++
  • std::vector
  • ANSI / WinAPI
  • Game Loop

Игра тип „tower defense“ в конзолата. Играчът избира брой кули, те се разполагат случайно по картата и стрелят по врагове в обсега си, преди да достигнат базата.

Архитектурни акценти: разделяне на .h и .cpp файлове, структури за обектите, основен game loop, изчисляване на обсег чрез Евклидово разстояние (std::sqrt) и цветно рендиране в конзолата.
